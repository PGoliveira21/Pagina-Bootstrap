## 📋 Sobre Este Projeto

Esta foi uma das minhas primeiras aplicações práticas de Front-End. O objetivo na época era entender e dominar os conceitos básicos de:
- Estruturação de páginas com **HTML5**.
- Estilização e responsividade utilizando o framework **Bootstrap**.
- Organização de diretórios (separação de CSS e imagens).
- Deploy e hospedagem estática via **GitHub Pages**.

---

## 💡 O Que Este Projeto Me Ensinou

Mais do que o código em si, este repositório representa a consolidação de fundamentos essenciais:
1. **Mentalidade Responsiva:** Entender como o grid system se adapta a diferentes telas.
2. **Leitura de Documentação:** Aprender a utilizar componentes de um framework de terceiros.
3. **Versionamento:** Meus primeiros passos sérios com Git e GitHub.
